To avoid $O(n^2)$ complexity, you can leverage the GPU’s parallel nature. Instead of "checking if a pixel is in a polygon," you "render the polygons and sample the base map."Step 1: ID Encoding. Assign each polygon a unique Uint32 ID. Encode this ID into the RGB channels of the polygon’s color.Step 2: Dual-Texture Sampling. Pass your base map (raster data) and your ID-encoded polygon mask into a custom fragment shader.Step 3: Off-screen Rendering (FBO). Render the scene to a WebGLRenderTarget.Step 4: Compute Shader (WebGL 2.0 / WebGPU).Use an Atomic Add operation in a compute shader (or a transform feedback loop).For every pixel, look up its ID (from the ID-encoded texture) and its value (from the base map).Accumulate the sum and the pixel count into a buffer indexed by the Polygon ID.Note: If using three.js, you can use three/examples/jsm/renderers/webgpu/WebGPURenderer.js to access Compute Shaders more easily, which support atomic operations specifically designed for this type of histogram/aggregation task.
